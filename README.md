# data09-20 · 예약 가능한 테니스 코트 조회

기준 위치·반경·기간·희망 시간·최소 연속 이용시간을 넣으면, 연속으로 예약할 수 있는 테니스 코트와 시간대를 거리순 목록과 위치 그림으로 보여 주는 도구

| 항목 | 내용 |
|---|---|
| 제출자 | 조윤제 |
| 과정 | 현장 데이터 수집·디지털화 전문가과정 1차수 (2026) |
| 진행 단계 | 1단계 개발 완료 (2026-09-29) — https://aebonlee.github.io/data09-20/ · 수강생 결정으로 2단계 진행 안 함 (2026-09-29) |
| 다음 개발 | 없음 — 네이버 지도 API 가 2025년 7월 이후 전면 유료라 2단계(네이버 연계)를 진행하지 않기로 수강생이 결정했습니다. 1단계 도구(직접 입력한 슬롯으로 연속 예약 판정)는 그대로 쓸 수 있습니다 |

## 실행 방법

**온라인에서 바로 쓰기: https://aebonlee.github.io/data09-20/**

내 PC에서 쓰려면 설치 없이 아래 두 방법 중 하나로 엽니다. 어느 방법이든 데이터는 서버로 가지 않고 이 브라우저 안에만 저장됩니다.

1. **파일로 바로 열기** — 이 폴더의 `index.html` 을 더블클릭해 크롬·엣지로 엽니다. 인터넷이 없어도 동작합니다(외부 라이브러리·지도 서비스를 부르지 않습니다).
2. **간이 서버로 열기** — 폴더에서 `python3 -m http.server 8000` 을 실행하고 브라우저에서 `http://localhost:8000` 을 엽니다.

처음 열면 코트 목록이 비어 있습니다. **「예시 데이터 불러오기」** 를 누르면 가상 코트 7곳과 10/01~10/15 예약 슬롯이 들어가고 화면 위에 「예시 데이터」 안내 띠가 표시됩니다. 「예시 테니스장 A」의 10/01~10/04 는 기획서 5.2 표, 「B」의 10/01 은 5.3 표 그대로입니다.

**네이버 예약 슬롯은 자동으로 가져오지 않습니다.** 제출 기획서 12~14장의 결론대로, 공식 연계 경로가 확인되기 전에는 비공식 내부 호출·화면 긁어오기를 하지 않습니다. 네이버 예약 페이지에서 확인한 가능 시간을 「예약 슬롯」에 적으면 연속 이용시간을 판정해 줍니다.

| 메뉴 | 하는 일 |
|---|---|
| 코트 검색 | 기준 위치(좌표·그림 클릭·현재 위치)·반경·기간·희망 시간·최소 연속 이용시간 → 거리순 결과 목록 + 위치 그림, 마우스 올림 요약, 날짜별 상세(시작 가능 시각), 네이버 예약 링크, 결과 CSV |
| 코트 목록 | 코트 입력·고치기·지우기(좌표·네이버 예약 여부·예약 URL·슬롯 단위 등), CSV 가져오기·내보내기 |
| 예약 슬롯 | 코트·날짜별 슬롯 표 클릭(○/×), 「18:00~19:00, 20:00~22:00」 한 줄 입력, 「가능 없음」·「비우기(미입력)」, CSV 두 형식 가져오기·내보내기 |
| 백업·복원 | 전체 데이터 백업 파일(JSON) 저장·복원, 예시 데이터, 모두 지우기 |
| 네이버 연계 준비 | 기획서 13장 검증 단계별 1단계 대체 방식과 2단계 PoC 확인 목록 |

- 데이터는 **이 브라우저(localStorage)에만** 저장됩니다. 브라우저 데이터를 지우면 사라지므로 「백업·복원」에서 백업 파일을 저장해 두세요. 마지막 검색 조건은 자동으로 기억합니다.
- 가져오기 연습용 예시 파일: `samples/예시_코트목록.csv`, `samples/예시_예약슬롯_슬롯별.csv`, `samples/예시_예약슬롯_하루한줄.csv` — 모두 가상 데이터입니다.
- 로직 테스트: `node test/logic.test.mjs` (의존성 없음)
- 예시 파일 다시 만들기: `node scripts/make-samples.js`
- DB 스크립트 검증: `./scripts/sqltest/run.sh` (로컬 PostgreSQL 필요)

## 1단계 구현 범위

기획서 5장 기능 목록(원본 기획서 FR-01~10) 기준입니다.

| 기능 | 상태 | 1단계에서 한 것 / 남은 것 |
|---|---|---|
| 기준 위치 (FR-01) | 대체 | 좌표 입력·한 줄 붙여 넣기·그림 클릭·코트 위치·현재 위치. **주소 → 좌표(지오코딩)는 2단계**(네이버 API 키 필요) |
| 검색 반경 (FR-02) | 완료 | 1·2·5·10 km·직접 입력, 하버사인 거리 |
| 테니스 코트 검색 (FR-03) | 대체 | 코트 목록 직접 입력·CSV. **장소 검색 API 자동 목록은 2단계** |
| 네이버 예약 필터 (FR-04) | 완료(입력 기반) | 코트마다 가능/불가/미확인, 「네이버 예약 가능 시설만」 |
| 기간·희망 시간 (FR-05·06) | 완료 | 최대 62일, 같은 날 안의 시간대(자정 넘김은 알려 주고 받지 않음) |
| 연속 예약 판정 (FR-07) | 완료 | 1~4시간, 슬롯 단위 S 코트별, 필요 연속 슬롯 T/S, 희망 시간대 경계·날짜 넘김 처리, 시작 가능 시각 |
| 지도 표시 (FR-08) | 대체 | 기준점 대비 방향·거리 SVG 위치 그림(반경 원·축척·북쪽), 목록과 연동. **NAVER Maps 는 2단계** |
| 마우스 올림 요약 (FR-09) | 완료 | 코트명·거리·네이버 예약·가능 시간·최대 연속·예약 링크, 목록 ↔ 표시 서로 강조 |
| 네이버 예약 연결 (FR-10) | 완료 | 사용자가 넣은 예약 URL(http·https 만), 없으면 네이버 지도 검색 링크 |
| 검색 조건 유지 (기능 8) | 완료 | 마지막 조건을 브라우저에 저장 |
| 예약 슬롯 수집 | 대체 | 사용자 확인 입력(표·한 줄·CSV), 최종 갱신 시각. **자동 수집은 2단계 게이트** |
